# 🦸‍♂️ Hero IO - The Ultimate App Store

Hero IO is a modern, responsive app store discovery platform built with React. It allows users to explore a wide range of mobile and web applications, view detailed analytics for each app, and manage their personal installations.

## 🚀 Live Demo
https://shamimappsstore.netlify.app/

## ✨ Features
- **Responsive Layout**: Seamless experience across all devices (Mobile, Tablet, Desktop).
- **Dynamic Routing**: Smooth navigation using `react-router-dom`.
- **Live Search**: Find apps instantly as you type.
- **Smart Sorting**: Sort apps by popularity (downloads).
- **Interactive Analytics**: Visualize app ratings and reviews with `Recharts`.
- **Local Installation Management**: 
  - Install apps to your local device (persisted in LocalStorage).
  - Track installed apps on a dedicated page.
  - Uninstall apps with one click.
- **Real-time Notifications**: Instant feedback via `react-hot-toast`.
- **Custom Error Handling**: User-friendly 404 page for broken links.
- **Optimized Performance**: Lazy loading and suspense for faster initial page loads.

## 🛠️ Technologies Used
- **Frontend Framework**: [React.js](https://reactjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Routing**: [React Router v6](https://reactrouter.com/)
- **Charts/Visualization**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Notifications**: [React Hot Toast](https://react-hot-toast.com/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Persistence**: LocalStorage API

## 📦 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/hero-io.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
